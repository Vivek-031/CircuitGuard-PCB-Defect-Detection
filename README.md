## 📌 Overview

CircuitGuard identifies PCB defects such as open circuits, shorts, and spurious copper using an image processing pipeline.

---

## 🎯 Features

* 🔍 Detects multiple PCB defect types
* ⚡ Automated inspection from images
* 🧠 Efficient image processing pipeline
* 🧩 Modular and scalable design

---
